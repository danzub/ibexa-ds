# ibexa-ds

i1 Design System — React component library for Ibexa DXP main menu items.

## Components

| Component | Location | Description |
|-----------|----------|-------------|
| `MainMenuItemBase` | `src/components/MainMenuItemBase` | Main menu item with Extended/Collapsed sizes and Enabled/Hover/Selected/Opened states |
| `MainMenuSubitem` | `src/components/MainMenuSubitem` | Sub-menu item with pin/drag states |
| `ModuleItem` | `src/components/ModuleItem` | Module switcher item for Qualifio modules |
| `CollapseButton` | `src/components/CollapseButton` | Sidebar collapse toggle |
| `Tooltip` | `src/components/Tooltip` | Tooltip wrapper |
| `Divider` | `src/components/Divider` | Visual separator |
| `MainMenuContextMenu` | `src/components/MainMenuContextMenu` | Context menu |

## Design Tokens

- Font: Mulish 14/21 Regular
- Item height: 40px
- Extended width: 240px
- Collapsed width: 40px
- Radius: 8px
- Brand pink: #dc5685
- Background hover: #262a2d
- Tooltip bg: #ba2157

## Showcase

Run `npm install && npm run dev` to view the showcase rendering all menu item variants.
